## Sobre

- Estagiário de TI na Prefeitura de São Paulo (SEGES/COPATS), com foco em soluções web, automação em Python e IA generativa com RAG para a gestão de parcerias com o terceiro setor.
- Graduando em Sistemas de Informação pela Faculdade Impacta (conclusão prevista em 12/2027).
- Backend em Java 21 (Spring Boot 3, Quarkus) e Python (Flask), com APIs REST, autenticação JWT, RBAC e arquitetura hexagonal.
- Frontend em React e Angular com TypeScript.
- CI/CD com GitHub Actions, Docker e testes automatizados; deploy em Render, Vercel e Supabase.
- IA aplicada: RAG, orquestração de agentes e desenvolvimento assistido por IA com Claude Code.
